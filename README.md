## Summary

**Covers Lectures 1–2. 10 marks.**

Set up VS Code, Live Server and DevTools; install Git and publish a repository with GitHub Pages; hand-write a three-page semantic HTML site.

**No CSS**, with a −1 deduction for any. Structure is far harder to mark when appearance hides it, and students who style early reach for `<div>` and fix things visually.

## Every task states its expected result

Each task in the handout is followed by a green **"What you should see"** box
giving the exact output, screen state or behaviour that task produces. A student
can tell whether they are finished without guessing or waiting for a mark, and
the boxes double as a diagnostic: if the screen does not match, the problem is
in that task, not three tasks later.

`instructor/VERIFICATION.md` records how every one of those values was produced.
They were captured by running the reference solution, not written from memory.

## The self-checker

Students copy `check.html` and `check.js` into their own project folder and open
it with Live Server. Keeping it same-origin avoids CORS entirely and means it
works locally and against the published site.

Expected on a correct submission: `index.html 19 · about.html 22 · projects.html 21` → **63 passed, 0 to fix**

Verified in the other direction too — a copy of the reference with six planted faults — skipped heading level, `alt="image"`, an inline `style`, a missing `figcaption`, `target="_blank"` without `rel="noopener"`, and a table missing `caption` and `scope` produced
a failure for each.

## Regenerating the handout

```bash
python3 instructor/build_handout.py COSC219_Lab1_Handout.docx
```

Needs `python-docx`. `instructor/labdoc.py` is the shared theme and component
toolkit used by every lab handout — the cover band, the expected-result box, the
callouts and the rubric all live there, so all eleven labs stay consistent.

## Background section

The handout opens with **Background you need** before Part A, so a student can
start the lab without re-reading two lectures first:

- a bar naming the lectures the material comes from
- **Figure 1** — where your work lives and how it gets published — the four places a file exists, and which command moves it between them
- **Everything this lab uses** — a reference table covering Git commands, the landmark elements, semantic tags, alt and scope

The table is deliberately dense; it is the thing students glance back at while
working rather than something they read once.

The figure is regenerated by `instructor/build_figures.py` (which needs
`instructor/svgfig.py`), and a copy is bundled in `instructor/figures/` so the
handout rebuilds without it.
