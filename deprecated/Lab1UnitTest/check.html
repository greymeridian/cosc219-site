Lab 1 — self-check

Checks most of the structural requirements. It is a helper, not the marker.

Put this file in your project folder. Copy check.html and check.js into the same folder as index.html, then open check.html with Live Server. It loads your pages from the same origin, so leave the box below as ./.
Your pages
Two things this cannot check. It runs in your browser, so it cannot see your commit history, and it cannot judge whether your alt text is meaningful — only that it exists. It also does not replace the W3C validator; run that too.
